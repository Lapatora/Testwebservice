## ❌ Найденные проблемы и исправления

### 1. Проблема с портом 5000

**Проблема:** Порт 5000 может быть занят системным процессом macOS (AirPlay Receiver)

**Решение:**
- Добавлена проверка доступности порта при запуске
- Понятные сообщения об ошибке если порт занят
- Инструкции как освободить порт или использовать другой

**Как проверить:**
```bash
cd server
npm run test-server
```

**Если порт занят:**
```bash
# Найти процесс
lsof -i :5000

# Освободить порт (если это не системный процесс)
lsof -ti:5000 | xargs kill -9

# Или использовать другой порт
PORT=5001 npm run dev
```

### 2. DATABASE_URL содержит шаблонные значения

**Проблема:** В `.env` файле указано `postgresql://username:password@localhost:5432/testwebservice`

**Решение:**
- Добавлена проверка на placeholder значения
- Сервер не запустится если DATABASE_URL содержит `username:password`
- Понятные инструкции как исправить

**Как исправить:**
```bash
# Откройте server/.env и измените:
# БЕЗ пароля (если пароль не установлен):
DATABASE_URL=postgresql://localhost:5432/testwebservice

# Или с пользователем (без пароля):
DATABASE_URL=postgresql://your_username@localhost:5432/testwebservice

# Или с пользователем и паролем:
DATABASE_URL=postgresql://username:password@localhost:5432/testwebservice
```

### 3. Отсутствие проверки конфигурации при старте

**Проблема:** Сервер пытался запуститься даже с неправильной конфигурацией

**Решение:**
- Добавлена проверка DATABASE_URL перед инициализацией БД
- Проверка на placeholder значения
- Понятные сообщения об ошибках

### 4. Обработка ошибок порта

**Проблема:** Если порт занят, ошибка была неочевидной

**Решение:**
- Добавлен обработчик ошибок для `EADDRINUSE`
- Понятные инструкции что делать
